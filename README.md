# Logistics-Sales-Performance-Dashboard

# Overview :
This project presents a Logistics & Sales Performance Dashboard built using Power BI, focusing on analyzing shipping performance, revenue trends, and order delivery efficiency.

The dashboard enables stakeholders to:

Monitor year-wise and monthly performance
Analyze shipping modes and delivery status
Track on-time vs delayed deliveries
Identify key trends impacting logistics efficiency

# Problem Statement : 

In logistics operations, tracking delivery performance and understanding delays is critical.
This dashboard helps answer:

Which shipping mode performs best?

How does delivery performance vary over time?

What is the trend of revenue and orders?

Where are delays happening?

# Key Features :
1. ## Year-wise Analysis
Dynamic year selection (2015–2018)
KPI tracking:
Total Revenue
Total Orders
Total Sales

2. ## Shipping Mode Analysis
Distribution of orders by:
Standard Class
Second Class
First Class
Same Day

3. ## Delivery Performance Tracking
On-time vs Late deliveries
Monthly trend analysis of delivery status

4. ## Sales Insights
Sales comparison across shipping modes
Identification of high-performing categories

5. ## Dynamic Filtering 
Quarter-based filtering
Multi-select filters:
Region
Department
Shipping Mode
Order Status
Customer Segment

# Key Insights :

Standard Class shipping contributes the highest volume of orders

On-time delivery fluctuates across months, indicating operational inconsistencies

Certain months show a drop in delivery performance → potential bottlenecks

Sales vary significantly based on shipping mode and delivery timelines
